# Hermes Gmail Agent — OAuth consent pages

This repository hosts the public home page and privacy policy for a **personal,
single-user** Google OAuth client ("Hermes Agent").

The client is used by one individual to let a locally-running personal assistant
read and manage **their own** Gmail, Calendar and Drive data. It is not offered as
a service, has no other users, and is not distributed.
