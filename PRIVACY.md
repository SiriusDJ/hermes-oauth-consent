# Privacy Policy — Hermes Gmail Agent

Last updated: 2026-11-06

## What this application is
"Hermes Agent" is a personal desktop assistant operated by a single individual
(Sirius Zhang). It authorizes access to Google accounts that the operator owns.

## What data is accessed
With the operator's explicit consent, the application requests OAuth scopes for
Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs and Google
Contacts. It reads message metadata and content, calendar events, and files only
as needed to perform the operator's own requests (for example summarising unread
mail or listing upcoming events).

## How data is used
Data is used solely to answer and act on the operator's own instructions on the
operator's own machine. It is not used for advertising, profiling, model training,
or any secondary purpose.

## Sharing
No Google user data is sold, rented, transferred, or disclosed to any third party.
Data is not shared with other users, advertisers, or data brokers. Limited
processing by the large-language-model provider used by the assistant happens only
to fulfil the operator's request and under that provider's API data-use terms.

## Storage and retention
OAuth credentials are stored locally on the operator's machine. Message content is
held only transiently in local caches used to build summaries and is deleted when
no longer needed. The operator can revoke access at any time at
https://myaccount.google.com/permissions, which immediately ends all access.

## Google API Limited Use
This application's use of Google user data adheres to the Google API Services User
Data Policy, including the Limited Use requirements.
